# 运行环境与兼容性

版本：1.0.0。记录日期：2026-10-22。

## 必需与可选能力

| 能力 | 要求与行为 |
| --- | --- |
| 阅读指令并保留多轮上下文 | 必需；每次依据用户实际回答选择后续问题 |
| ask／用户输入工具 | 优先使用；缺失或模式不支持时改为普通对话 |
| 接收自由回答 | 必需；不能只接受工具默认选项或把预选项当作回答 |
| 文件上传 | 可选；无上传能力时粘贴学习材料与指令 |
| 网络与资料检索 | 视主题需要；不是本 Skill 自带能力 |
| 运行 Python 和 Git | 仅维护、检查及打包需要，学习者使用 Skill 不需要 |

Skill 是指令文件，不自带 MCP 服务、账户、API Key 或工具实现。单个通用版本不绑定 ChatGPT、DeepSeek 或特定模型；这不代表已验证所有客户端兼容。

## 工具适配

宿主可能把提问接口命名为 `request_user_input`、`request_user_input_async`、`AskUserQuestion` 或其他名称。实际名称、可用模式与参数以当前宿主为准；不为了调用受限工具而自行切换工作模式。

诊断选项不能带“正确答案推荐”或默认答案暗示。若工具要求此类呈现，应改用其支持的自由文本问题或普通文字提问，保持问题中立。工具不支持长篇回答时，也应允许用户直接在对话中补充。

异步发问后必须等待真实回复。等待期间可整理已知信息，但不能假装收到回答或提前展开依赖回答的教学。

## 故障反馈

在仓库提交 Issue，附 Skill 版本、宿主、模型（如可知）、工具可用性、最小复现输入和脱敏对话。注明问题发生在诊断、确认、讲解还是小题环节，便于区分提示词问题与宿主限制。
