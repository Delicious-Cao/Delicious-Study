# 完整对话示例

这两个例子是为说明 Skill 行为而人工编写的对话，非真实学习者日志、实际 ask 调用记录或独立模型评测。示例中的用户回答是写作设定，不用于证明学习效果。

| 示例 | 诊断目标 | 验证环节 |
| --- | --- | --- |
| [溶液的依数性](colligative-properties.md) | 质量摩尔浓度的分母与溶质粒子数 | 浓度不同的两种溶质能否产生相同沸点升高 |
| [导数与函数单调性](derivatives.md) | 导数为零是否足以判断极值或单调性 | 对一个零点处导数为零的函数判断整个区间趋势 |

按对话顺序阅读。每次“AI 提问”在真实使用中应通过可用提问工具发出，或在普通对话中提出并等待回复。后文出现的答案不应在真实提问时同时展示给学习者。

学科实例只用于演示流程：化学例子明确采用理想稀溶液与完全解离等条件；数学例子限定了讨论区间与函数。实际教学应以用户材料和具体适用条件为准。
