# 示例：导数与函数单调性

人工编写的流程示例，非真实用户记录。重点展示“答对但理由不完整”时如何继续确认。

## 第 1 轮：了解目标与已有步骤

**用户：** 我不会用导数判断函数单调性。

**AI 提问：** 你现在是不会求导，还是能求导但不知道怎么用结果？可以提供一个函数，或者写出你目前做到的步骤。

**用户：** 会求导。比如 f(x) = x³，f′(x) = 3x²，但我不知道 x = 0 那里怎么算。

## 第 2 轮：定位误解

**AI 提问：** 你认为 f′(0) = 0 能直接说明什么：函数在这里有极值、整个函数不再递增，还是仅凭这一步还不能确定？说一下理由，不确定也可以。

**用户：** 我以为导数等于零就是极值，所以 0 左右应该一增一减。

## 第 3 轮：确认起点

**AI：** 求导结果是对的。目前的卡点是把“某一点导数为零”直接当成“这一点有极值”，还没有检查该点两侧的导数符号。

**AI 提问：** 我先说明点上的导数值与区间内导数符号的区别，再回到这个函数，可以吗？

**用户：** 可以。

## 针对性讲解

**AI：** 对区间内可导的函数，区间上导数始终为正，可以推出函数严格递增；始终为负，可以推出严格递减。仅知道某一点导数为零，不能判断该点是否为极值，更不能直接决定整个区间的单调性。

对 x³，x < 0 与 x > 0 时，3x² 都为正；只有 x = 0 时导数为零，左右没有出现正负号的切换。它在整个实数轴上严格递增，0 不是极值点。一个孤立的零导数点并不必然破坏严格单调性。

这里也不能把“导数非负”与“必然严格递增”无条件等同：导数非负可推出非递减，若还要判断严格递增，需要排除函数在某个非退化子区间恒定等情况。

## 最后的小题：先判断，再检查理由

**AI 提问：** g(x) = x³ − 3x² + 3x，g′(x) = 3(x − 1)²。请判断它在整个实数轴上的单调性，并说明 x = 1 是否为极值点及理由。不必再求导。

**用户：** 严格递增，1 不是极值点，因为导数非负。

**AI 补问：** 你的结论正确，但“导数非负”这句话本身还没有解释严格性。除了 x = 1，其他点的导数是什么符号？有没有一整段区间的导数都为零？

**用户：** 除了 1 都大于零，没有任何一整段导数为零。在 1 两边都是正，没有变成负，所以这里没有极大或极小。

**AI 反馈：** 这次理由补全了：你区分了孤立零点与整段恒定，也检查了两侧符号。此题验证了这类函数的单调性与极值判断；尚未检验有多个临界点、不可导点或间断点的情况。
